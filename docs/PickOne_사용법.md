# PickOne 사용법 (BETA Ver-0.1)

> 사진 셀렉팅을 **서버·구독료 0원**으로 처리하는 포터블 프로그램.
> 작가가 저용량 미리보기를 **HTML 파일 하나**로 만들어 보내면, 클라이언트가 브라우저에서
> 원하는 컷을 고르고, 그 결과로 **원본을 자동으로 골라 복사**합니다.
> 제작: Unknown · 2026 · YouTube @unknown8563

---

## 0. 한눈에 보는 흐름

```
[작가] 사진 폴더 → PickOne으로 갤러리 HTML 1개 생성 → 카톡/메일로 클라이언트에게 전송
                                   ↓
[클라이언트] HTML 더블클릭 → 사진 고르기(별점·메모) → "결과 파일 저장"(.json) → 작가에게 전송
                                   ↓
[작가] PickOne 회수 탭에 결과 파일 드롭 → 폴더 만들고 원본 자동 복사 ✅
```

- 클라이언트는 **설치·회원가입·인터넷 불필요**. 브라우저만 있으면 됩니다.
- 작가가 보내는 건 **원본이 아니라 저용량 미리보기**입니다(원본은 작가 PC에 그대로).

---

## 1. 설치 / 실행

- **Windows**: `PickOne.exe` 더블클릭. 설치 과정 없는 단일 포터블 실행 파일입니다.
- **macOS**: `PickOne.app` 실행(추후 제공). 처음 한 번은 우클릭 → "열기"로 실행하세요.
- 화면 위쪽 **패키징 / 회수** 두 개의 탭으로 나뉩니다.

---

## 2. 패키징 탭 — 갤러리 만들어 보내기

### 2-1. 사진 넣기
- 사진 **폴더나 파일을 창에 드래그**(또는 안내 영역 클릭으로 폴더 선택).
- 하위 폴더까지 전부 모아 **하나의 갤러리로 평탄화**합니다. 파일명이 겹치면 폴더명을 앞에 붙여 구분합니다.
- 지원: **JPG / PNG / HEIC / TIFF / RAW**(CR3 등 — 내장 미리보기 추출). **영상은 제외**(사진만).

### 2-2. 설정 항목
| 항목 | 설명 |
|---|---|
| **제목** | 갤러리 제목 = 만들어질 HTML 파일 이름. |
| **목표 장수** | 클라이언트에게 "N장 골라주세요" 가이드 표시. 기본 **제한 없음**(숫자 입력 시 그 수를 기준으로 카운트). |
| **안내 문구** | 클라이언트 화면 상단에 보일 안내 메시지. |
| **목표 파일 용량(MB)** | **자동**(기본)이면 화질 손실 없는 선에서 최대한 줄입니다. 숫자를 넣으면 **그 용량을 절대 넘기지 않도록** 사진 화질을 자동 조절(여유 있으면 더 선명하게, 넘치면 더 줄여서). |

> **분할은 없습니다.** 사진이 아무리 많아도 항상 **HTML 파일 1개**로 나옵니다.
> 목표 용량을 지정하면 그 용량 안에 들어가도록 알아서 맞춰줍니다.

### 2-3. 생성
- **출력 폴더**를 정하고 **"갤러리 HTML 생성"** 클릭 → `제목.html` 1개가 생성됩니다.
- 결과 목록의 항목을 **더블클릭하면 브라우저 미리보기**로 확인할 수 있습니다.
- 이 HTML을 카톡/메일로 클라이언트에게 보내면 됩니다.
  - 카톡이 .html 첨부를 막는 경우, 파일을 압축(zip)하거나 메일/드라이브 링크로 보내세요.

---

## 3. 클라이언트 화면 — 사진 고르기 (브라우저)

클라이언트에게 이렇게 안내하면 됩니다.

1. 받은 **HTML 파일을 더블클릭**하면 브라우저에서 갤러리가 열립니다.
2. 사진을 **한 번 클릭 = 선택/해제**, **더블클릭 = 크게 보기(라이트박스)**.
   - 크게 보기 화면에서 좌우로 넘기며 **선택·★별점·메모**를 남길 수 있습니다.
3. 상단 **보기 필터**로 모아 볼 수 있습니다: **전체 / 선택만 / 메모 있는 것 / ★5~★1**.
4. 다 고르면 아래 **"📄 결과 파일 저장"** 버튼 → 작은 결과 파일(`제목_셀렉결과.json`)이 저장됩니다.
   **이 파일을 작가에게 카톡/메일로 보내면 끝.**
   - 복사가 막힌 환경을 위해 "텍스트 복사" 버튼도 있습니다(보조 수단).

> **자동 저장 안내(중요):** 선택·별점·메모는 그 브라우저에 **자동 저장**되어, 창을 닫았다 다시 열어도
> 이어서 작업할 수 있습니다. **단, HTML 파일을 다른 PC·기기로 옮기면 그동안 체크한 내용은 따라가지 않습니다**
> (같은 브라우저에서만 이어집니다). 기기를 바꿔야 하면 "선택 백업 저장"을 이용하세요.

---

## 4. 회수 탭 — 원본 자동 복사

1. **① 원본 폴더**: 패키징할 때 사용한 원본 사진 폴더를 지정합니다.
2. **② 결과 파일**: 클라이언트가 보낸 **`.json` 파일을 드래그**합니다.
   - 텍스트로 받았다면 붙여넣기 후 "텍스트 추가"(여러 번 누적 가능).
3. **③ 파싱 미리보기**: 찾은 사진 목록과 매칭/미매칭 수를 확인합니다.
4. **④ 대상 위치 + 폴더 이름**:
   - **대상 위치** = 셀렉본을 담을 상위 폴더.
   - **폴더 이름** = 새로 만들 폴더명. **비워 두면 받은 결과 파일 이름**으로 자동 생성됩니다.
5. **"선택본 복사 실행"** → `대상 위치\폴더 이름\` 폴더를 만들고 그 안에 **원본을 복사**합니다.
   - **원본은 그대로 보존**(이동이 아니라 복사). 파일명이 겹치면 `_2` 식으로 자동 구분.
   - (옵션) 별점·메모를 `_셀렉결과.txt`로 함께 저장.

---

## 5. 자주 묻는 점

- **원본 화질이 그대로 전달되나요?** 아니요. 전달되는 건 **선택용 저용량 미리보기**입니다.
  최종 원본은 회수 탭이 작가 PC의 원본에서 골라 복사합니다.
- **사진이 수천 장이면?** 그래도 파일은 1개로 나옵니다. 다만 용량이 커지면 브라우저가 무거울 수 있으니,
  필요하면 **목표 파일 용량(MB)**을 지정해 가볍게 만드세요.
- **클라이언트가 실수로 닫았어요.** 같은 PC·같은 브라우저에서 다시 열면 고른 내용이 그대로 있습니다.
- **파일명을 손으로 적다 틀릴 일은?** 없습니다. 결과 파일(.json)의 내부 식별자로 정확히 매칭합니다.
